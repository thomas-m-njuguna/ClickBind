Questions

Windows says "Windows protected your PC". Is that normal?

Yes. The setup is not code-signed yet, so SmartScreen warns on first run. Choose More info, then Run anyway.

Does it need administrator rights?

No. ClickBind installs under %LOCALAPPDATA%\Programs\ClickBind and only touches your own user settings.

How do I uninstall it?

Use Uninstall ClickBind in the Start menu, or delete the installed folder after removing the shortcuts. Settings live in %APPDATA%\ClickBind.

Is there a portable version?

Yes — download or clone the repository and run build.cmd, then launch dist\ClickBind.exe.
