Common questions

Why does SmartScreen warn about the installer?

The installer is not code-signed. If Windows shows Windows protected your PC, choose More info, then Run anyway.

Do I need administrator rights?

No. ClickBind installs for your Windows account and stores settings there.

How do I uninstall ClickBind?

Choose Uninstall ClickBind in the Start menu. Your settings are stored in %APPDATA%\ClickBind.

Can I run ClickBind without installing?

Yes. Build from the repository with build.cmd, then run dist\ClickBind.exe.
